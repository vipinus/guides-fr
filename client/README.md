# Guides des clients · Installation et configuration

Des instructions pas à pas pour **installer et connecter** chaque méthode d'accès : Cisco AnyConnect, Hiddify, l'extension de proxy web, OpenVPN et la méthode Privé (Tailscale), ainsi que la marche à suivre quand iOS refuse d'installer une app, l'installation de Telegram / Discord, la configuration de nombreux appareils en une fois, et que faire quand un logiciel comme Dropbox demande un proxy. Pour choisir une méthode, voir [Quelle méthode de connexion pour quelle situation](../network/02-choose-your-connection-method.md) ; si c'est installé mais que la connexion échoue, voir [Dépannage](../troubleshooting/).
