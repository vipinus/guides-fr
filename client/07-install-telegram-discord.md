# 07 · Installer Telegram et Discord

Ces deux outils de discussion de groupe sont très utilisés par les communautés chinoises à l'étranger, et les groupes d'assistance y sont aussi hébergés. Les installer n'est pas difficile en soi ; le point de blocage est généralement que « la boutique d'applis ne s'ouvre pas ».

## Telegram

| Plateforme | Installation |
|---|---|
| Windows / macOS / Linux / Android | [La page de contact de ce site](https://www.leotun.com/fr/contact?utm_source=github&utm_content=client-07) propose des installateurs identiques aux versions officielles (pour Android, c'est l'APK officiel complet, sans passer par Google Play) ; vous pouvez aussi passer par le site officiel <https://desktop.telegram.org> ou par Google Play |
| iOS | Uniquement l'App Store ; pour le problème de région de la boutique, voir [l'article précédent](06-ios-app-store.md) |

L'inscription exige un numéro de mobile capable de recevoir des SMS. Ensuite, vous pouvez définir un nom d'utilisateur, et les autres n'ont pas besoin de connaître votre numéro.

## Discord

| Plateforme | Installation |
|---|---|
| Windows / macOS / Linux | Site officiel <https://discord.com/download> |
| Android | Officiellement disponible uniquement sur Google Play. Les téléphones qui ne peuvent pas installer Play peuvent utiliser le paquet fractionné (.apks), qui exige d'installer d'abord l'installateur open source SAI et ne fonctionne que sur les appareils arm64 |
| iOS | App Store |

## Après l'installation

- Lisez le règlement du groupe avant d'y entrer. La plupart des groupes interdisent la publicité. Avant de poser une question, cherchez d'abord dans l'historique du groupe ; beaucoup de questions y ont déjà une réponse.
- Si l'appli refuse de s'installer ou plante au lancement, donnez à l'assistance la version de votre système et le modèle de l'appareil ; la plupart du temps, c'est le modèle ou la version qui ne correspond pas.
