# Accéder à la Chine depuis l'étranger · Tout ce qui exige une IP chinoise

Quand vous êtes hors de Chine, de nombreux services chinois vous refusent parce que votre IP n'est pas en Chine continentale : vidéo, musique, services administratifs, banque, réservation de billets, jeux. Un article par situation, qui explique clairement **pourquoi vous êtes bloqué, comment y remédier, et quels autres pièges vous attendent**.

**L'article le plus demandé : [Débloquer les sites vidéo chinois depuis l'étranger avec un routeur](../router/06-unlock-chinese-video-with-router.md)** — le téléviseur, la box TV et tous les appareils du foyer sont configurés une fois pour toutes, et vous regardez iQIYI, Tencent Video et Yangshipin dès que vous êtes sur le Wi-Fi.
